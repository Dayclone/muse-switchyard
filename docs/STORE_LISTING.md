## Description
Switchyard lets you keep several muse.ai accounts in one browser and swap between them in one click (or Alt+Shift+S) without waiting for a new login code every time.

- Fast switching: log into each account once, save it, then switch whenever you like.
- Encrypted vault: saved sessions are encrypted with your passphrase (PBKDF2 + AES-256-GCM), auto-lock when idle or when the screen locks.
- Longer-lived sessions: restored cookies get a longer expiry, rotated tokens are re-saved, and a logged-out guard stops it overwriting a good saved copy.
- Optional auto-approve: turn on the master switch to have Switchyard click Allow on Muse approval cards for the types you pick (messages, Marketplace listings, or everything). It has a learn mode, rate limit and a log, and is off by default.
- Private by design: no servers, no analytics, no network calls of its own. Everything stays in your browser.

Switchyard is an unofficial, independent project. It is not made, endorsed or supported by Meta or Muse. Using several accounts or automating clicks may be restricted by the service's terms; that is your call and your risk.

Open source (MIT): https://github.com/Dayclone/muse-switchyard

## Single purpose
Manage multiple muse.ai account sessions in one browser: save, switch and keep them signed in, with an opt-in helper that approves Muse's own approval prompts for those accounts.

## Permission justifications
- cookies, https://*.muse.ai/*: read and restore the session cookies of accounts the user saves.
- storage: store the encrypted vault and settings locally.
- scripting: read and restore localStorage/sessionStorage of open muse.ai tabs.
- alarms, idle: auto-lock the vault, refresh cookie lifetimes, run the optional account loop.
- Content script on muse.ai: optional auto-approve; detects approval cards and clicks Allow when the user has enabled it. It only sends log messages to the extension.
- Optional hosts (meta.ai, meta.com, facebook.com): requested at runtime only if the user adds them, because muse.ai signs in through Meta.

## Data-use disclosures (Chrome dashboard)
- Collects: authentication information (session cookies), stored locally and encrypted; user activity limited to a local approval log.
- Not sold, not transferred to third parties, not used for unrelated purposes, not used for creditworthiness.
- Remote code: none.
